# 高质量提示词的五个要素

一个可执行的提示词通常包括：

1. **角色**：希望 AI 扮演什么角色？
2. **任务**：具体要完成什么？
3. **背景**：面向谁、用于什么场景？输入材料
4. **要求**：格式、风格、长度、评价标准
5. **输出**：希望以表格、清单、提纲还是代码呈现



提示词公式：

**角色 + 任务 + 背景 + 约束 + 输出格式 + 评价标准**


# 一个可复用的提示词模板

```text
你是一名【专业/角色】。

完成【具体任务】。

背景信息：
- 课程/项目：
- 学习者/研究对象：
- 使用场景：
- 已有材料：输入文件，链接等

具体要求：
1. 【要求一】
2. 【要求二】
3. 【要求三】


输出：

按照【表格/提纲/清单/代码/JSON】格式输出。
请标注不确定信息，并列出需要人工核验的内容。
```


# 参考案例

你是一个软件产品经理，

任务：给一个客服智能体编写用户故事和验收标准

背景：
用户故事是敏捷开发中描述功能需求的核心工具。 标准模板：
作为一名 [角色]， 我想要 [某种功能]， 以便能够 [实现某种价值]。
用户故事需要满足INVEST 原则：

* Independent（独立的）
* Negotiable（可协商的）
* Valuable（有价值的）
* Estimable（可估算的）
* Small（小巧的）
* Testable（可测试的）

验收标准 (Acceptance Criteria - Gherkin 语法)

输入：

参考附件文件。


输出：
用户故事和验收标准

以下是一个例子。
用户故事:
  角色: 作为一名结构工程师
  功能: 我想要一键导入 STEP 格式的文件
  价值: 从而避免手动转换格式造成的精度损失。

验收标准 (Acceptance Criteria - Gherkin 语法):
  场景: 导入一个有效的 STEP 模型
    Given 用户在主界面并点击了"导入"按钮
    When 用户选择了一个标准的 50MB "engine.step" 文件
    Then 系统应在 5.0 秒内完成解析并无损渲染
    And 系统状态栏应显示 "导入成功，包含 1420 个面"
