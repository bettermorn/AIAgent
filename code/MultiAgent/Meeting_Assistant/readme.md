基于 **AutoGen + DeepSeek + Python** 的“智能会议助手”完整示例。

系统包含两个 Agent：

- **提取 Agent**：读取会议纪要，提取待办事项、负责人、截止时间等信息；
- **审核 Agent**：审核提取结果，检查负责人、截止时间等字段是否缺失，并输出最终结构化结果。

整体流程如下：

```text
会议纪要
   ↓
提取 Agent
   ↓
初步任务列表 JSON
   ↓
审核 Agent
   ↓
审核后的最终结构化结果
```

# 一、安装依赖

建议使用 Python 3.10 及以上版本。

```bash
pip install -U autogen-agentchat autogen-ext[openai] pydantic python-dotenv
```

创建项目目录：

```text
meeting_assistant/
├── main.py
├── meeting_minutes.txt
└── .env
```

---

# 二、配置 DeepSeek API Key

在 `.env` 文件中配置：

```env
DEEPSEEK_API_KEY=你的DeepSeek_API_Key
```

DeepSeek 提供兼容 OpenAI API 的接口，因此可以通过 AutoGen 的 `OpenAIChatCompletionClient` 调用。

# 三、会议纪要示例

创建 `meeting_minutes.txt`：

```text
会议主题：智能客服项目周会

会议日期：2025-01-15

参会人员：
张伟、李娜、王强、赵敏

会议内容：

1. 张伟负责完成用户登录模块的接口开发，计划在1月20日前完成。
2. 李娜需要整理客服系统的需求文档，本周五之前提交。
3. 王强负责准备下周的系统演示。
4. 数据分析模块需要补充用户画像功能，具体负责人暂未确定。
5. 赵敏提出，需要在月底前完成项目预算评估，但暂时没有明确由谁负责。
6. 下次会议讨论系统上线计划。
```
# 四、运行程序

```bash
python main.py
```

程序会：

1. 读取 `meeting_minutes.txt`；
2. 调用提取 Agent；
3. 提取待办事项；
4. 判断负责人和截止时间；
5. 调用审核 Agent；
6. 检查缺失字段；
7. 保存到 `meeting_result.json`；
8. 将最终结果打印到终端。

# 六、核心设计说明

## 1. 为什么使用两个 Agent？

将任务拆分为两个 Agent，可以降低单个 Agent 同时处理多个目标时产生错误的概率。

### 提取 Agent

主要负责：

- 识别任务；
- 提取负责人；
- 提取截止时间；
- 记录任务原文依据；
- 初步标记缺失字段。

### 审核 Agent

主要负责：

- 发现提取错误；
- 防止把普通讨论误识别为任务；
- 检查负责人是否明确；
- 检查时间是否明确；
- 防止模型自动猜测信息；
- 输出最终结果。

---

## 2. 为什么要保留 `source` 字段？

`source` 用来记录任务对应的会议纪要原文。

例如：

```json
{
  "action": "完成项目预算评估",
  "source": "赵敏提出，需要在月底前完成项目预算评估，但暂时没有明确由谁负责。"
}
```

这样可以方便：

- 人工复核；
- 追溯任务来源；
- 审查模型是否误读；
- 在前端展示原始依据。

---

## 3. 为什么负责人和截止时间使用 `null`？

不应该让模型根据上下文擅自推测。

例如：

```text
数据分析模块需要补充用户画像功能，具体负责人暂未确定。
```

正确结果应该是：

```json
{
  "owner": null,
  "deadline": null,
  "missing_info": [
    "负责人",
    "截止时间"
  ]
}
```

而不应该根据“数据分析模块”猜测负责人是数据分析人员。


# 七、简化后的系统架构

```text
用户上传会议纪要
        │
        ▼
文件读取模块
        │
        ▼
提取 Agent
  ├── 任务识别
  ├── 负责人识别
  ├── 截止时间识别
  └── 缺失信息初检
        │
        ▼
审核 Agent
  ├── 任务真实性检查
  ├── 字段完整性检查
  ├── 防止信息猜测
  └── 生成审核意见
        │
        ▼
Pydantic 数据校验
        │
        ▼
JSON / 数据库 / Web 页面
```

这个示例已经覆盖了题目要求的六项功能：

1. 读取会议纪要；
2. 提取待办事项；
3. 判断负责人和截止时间；
4. 生成任务列表；
5. 检查缺失信息；
6. 输出结构化 JSON 结果。
